# Juan Reza

I build websites and software by directing AI coding agents ([Claude Code](https://claude.com/claude-code)), and I
run [Reza Systems](https://rezasystems.com), a one-person web studio in Midland, Texas.

**How I work:** I write a clear spec, the agent builds it, automated checks catch what it misses, and I review the
result before anything ships. Instruction files and hooks keep the agents inside the rules, and nothing goes live
without my go-ahead.

### Shipped

- **[Tim Snelson's Pumping Unit Service](https://www.timsnelson.com/)**: the company's first website, live since July 2026.
- **[Bold Gold Lawn Services](https://boldgoldlawnservice.com/)**: 100 on Google's accessibility and SEO audits.
- **[Circle H Haven Foundation](https://www.circlehhaven.com/)**: a nonprofit horse and donkey rescue, plus

- **A monthly client report** in Python: site visits, Google Search Console, uptime and form requests, turned into a
  plain-English HTML and PDF report on a schedule.
